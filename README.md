# Bilan Prévention

Application web pour digitaliser le Bilan de Prévention en officine.

## Déploiement Vercel

Ce projet est prêt à être déployé sur Vercel. Variables d'environnement à configurer :

- `RESEND_API_KEY` : votre clé API Resend
- `PHARMACY_EMAIL` : adresse mail de la pharmacie destinataire
